# Contributing to alltrader

1. Read `AGENTS.md` and `AI_PROJECT_HANDOFF.md`.
2. Keep changes small, reproducible, and evidence-backed.
3. Add or update tests for behavior changes.
4. Do not commit secrets, private datasets, broker credentials, or generated local state.
5. Explain data licenses, assumptions, benchmarks, costs, and failure conditions in research changes.

Open a discussion or issue before adding live-trading integrations or making claims about returns.
