# Decisions

## 2026-11-09 — Public repository and license

Decision: Create `ElevenZhou/alltrader` as a public GitHub repository under Apache-2.0.

Reason: The project is intended for direct open-source collaboration; Apache-2.0 provides a permissive baseline with an explicit patent grant. Dependency licenses remain subject to review.

## 2026-11-09 — Paper-first boundary

Decision: The initial repository supports research and paper workflows only.

Reason: Existing evidence supports a research and validation direction, while live execution, data entitlements, and production controls are not yet specified. Live or production changes require explicit confirmation.
