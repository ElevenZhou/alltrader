# Project Overview

`alltrader` is a public research project for building auditable trading-analysis agents. Its differentiator is the evidence chain around a method, rather than a persona prompt or an unverified performance claim.

## Phase 0 conclusion

The existing ecosystem provides useful building blocks: multi-agent orchestration, quantitative research/backtesting, weight-centric strategy contracts, and versioned research assets. It does not remove the need to verify sources, licenses, data quality, costs, and failure modes.

The project therefore starts with paper research and a shared output contract. Live execution is a later, separately approved milestone.
